## ⚡ Vercel এ ডিপ্লয় করার নিয়ম (How to Deploy to Vercel)

এই প্রজেক্টটি Vercel এ সার্ভারলেস ডিপ্লয়মেন্টের জন্য সম্পূর্ণভাবে কনফিগার করা আছে (`vercel.json` এবং Node.js Serverless Functions সহ)।

### ধাপ ১: GitHub এ কোড আপলোড করুন
1. [GitHub.com](https://github.com) এ লগইন করে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `aponhat-store`)।
2. আপনার কম্পিউটারের টার্মিনালে এই ফোল্ডারে গিয়ে কমান্ডগুলো রান করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - AponHat Full Store"
   git branch -M main
   git remote add origin https://github.com/<your-username>/aponhat-store.git
   git push -u origin main
   ```
   *(অথবা GitHub ওয়েবসাইটে গিয়ে `Add file` > `Upload files` থেকে সব ফাইল ড্র্যাগ-অ্যান্ড-ড্রপ করে আপলোড করতে পারেন)*

### ধাপ ২: Vercel এ ডিপ্লয় করুন
1. [Vercel.com](https://vercel.com) এ যান এবং GitHub দিয়ে লগইন করুন।
2. **"Add New..."** ➔ **"Project"** এ ক্লিক করুন।
3. আপনার তৈরি করা `aponhat-store` রিপোজিটরিটি সিলেক্ট করে **"Import"** এ ক্লিক করুন।
4. Vercel স্বয়ংক্রিয়ভাবে সেটিংস ডিটেক্ট করবে:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. **"Deploy"** বাটনে ক্লিক করুন!
   - ১ মিনিটের মধ্যেই আপনার ওয়েবসাইট লাইভ হয়ে যাবে (যেমন: `https://aponhat-store.vercel.app`)।

## 💻 লোকাল কম্পিউটারে রান করার নিয়ম (Local Development)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ফ্রন্টএন্ড রান করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:5173`

### ৩. ব্যাকএন্ড পিএইচপি রান করুন (ঐচ্ছিক - লোকাল ডেভেলপমেন্টের জন্য):
```bash
php -S 127.0.0.1:8000
```
